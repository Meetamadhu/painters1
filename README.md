# Painter Melbourne

Contest experience site for a residential decorating brand. The prototype is a full-page journey through light, surface, and Melbourne suburbs — not a standard services brochure.

Live: [painters1.vercel.app](https://painters1.vercel.app)

## What’s in the prototype

- Brand-world homepage with time-of-day lighting and destination rooms
- Finish exploration, case studies, and suburb pages
- Quote atelier and a contest-submission dossier view
- Toggle between the client prototype and the contest presentation

## Stack

React 19, TypeScript, Vite, Tailwind CSS, Motion

No backend and **no API keys**. The app does not call Gemini or any other AI service.

## Run locally

```bash
npm install
npm run dev
```

Opens at `http://127.0.0.1:5174`.
